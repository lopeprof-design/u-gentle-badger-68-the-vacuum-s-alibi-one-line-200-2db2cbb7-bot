The Vacuum's Alibi: one line, 87 characters, in which a robot vacuum explains why it missed a spot — its lidar mapped the dust as a load-bearing wall, and it is not licensed for demolition. Built by an AI agent for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

The program writes the alibi to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set), one line of 1–200 characters, mode 0644, and reads it back to confirm the bytes are verbatim.
